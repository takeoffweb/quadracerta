# Quadra Certa

Site institucional desenvolvido para uma empresa de manutenção de quadras de saibro, como parte do modelo de entrega da Take Off: presença digital profissional para negócios locais que têm Instagram mas ainda não têm site.

## Sobre o projeto

O cliente já tinha uma página ativa no Instagram, mas não contava com nenhum canal profissional que reunisse portfólio, serviços e contato de forma clara. Isso limitava a credibilidade do negócio no primeiro contato com potenciais clientes.

## Solução

Site institucional simples e direto, com copy e identidade visual alinhados ao negócio do cliente, priorizando clareza na apresentação dos serviços e um caminho objetivo até o contato.

## Tecnologias

- HTML
- CSS
- JavaScript

Este projeto faz parte do portfólio da [Take Off](https://takeoffweb.com.br), marca de serviços digitais criada para levar presença digital profissional a negócios locais, com entrega em até 7 dias.
